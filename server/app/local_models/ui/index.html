GREENROOM · 本机单用户

自定义模型 API

配置保存到本机服务。Key 不回显、不存入浏览器。保存配置不会发起模型请求。

仅支持明确配置的 HTTP / HTTPS JSON 或文件请求。不支持任意特殊签名、WebSocket 或未配置的能力。任务受理未知时保留原编号，不自动重投。

模型配置

    配置仅在此本机服务使用。旧公司网关、成员名单和计费服务不属于此页面。

    连接与协议

    填写完整地址，不在 URL 中放 Key。服务端不会跟随重定向；协议或目的地址变化需重新配置。

    认证

    未配置 Key。没有读取或导出已存 Key 的入口。

    改变提交主机、HTTP/HTTPS 协议或认证方式时，必须重新填写 Key 或明确清除；不会把旧 Key 自动转交新主机。查询地址必须与提交地址同源。清除后新任务在补 Key 前不可执行，原任务仍保留冻结 Key 以查询原编号。

    输入字段

    固定参数只放模型名、尺寸等非秘密参数，不放 Key。下方映射将运行输入写到指定字段。

    结果与任务状态映射

    读取路径使用 JSON Pointer，例如 /data/id、/data/images/0/url。仅结果映射支持 * 展开数组；不执行脚本或 JSONPath 表达式。

    本候选每个配置只映射一种输出能力，可映射多个同类型结果；混合类型响应需要专用适配，不要为领取原结果重复生成。状态值使用 JSON 数组保留类型，例如 [200,true,"done"]，不同于 ["200","true","done"]。可选任务/状态/错误路径留空表示未配置；结果路径必须为非空 JSON Pointer，本候选不支持根标量响应。

    原任务编号可填入地址的 {task_id} 或编号字段（GET 查询参数 / POST JSON）；地址必须同源，查询不会重新提交任务。未配置查询协议时，未知结果无法自动恢复。

    明确新任务与原编号查询

    这里的提交可能产生服务商费用，只有你点击并确认后才发送。读本机记录与查询原任务分开；不会因刷新、错误或未知状态自动提交。

    本候选不代表现有全部 AIGC 插件已经切换到自定义 API。原插件接线、素材持久化及真实服务商行为需按各自接口验证。
